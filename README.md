# Equity Analysis & CAPM Modeling

This repository contains two finance-focused analytical projects demonstrating practical application of equity analysis, financial statement interpretation, and risk–return modeling using real market data. The projects are designed to reflect skills relevant to investment banking, valuation, and equity research roles.

The code and analytical workflow were refined and optimized with the assistance of **Claude AI**, ensuring cleaner structure, better readability, and improved efficiency.

---

## Projects Included

### 1. JP Morgan Chase – Financial Analysis

A detailed financial analysis of **JP Morgan Chase & Co.**, focusing on understanding business performance, financial strength, and key value drivers through structured analysis of financial statements and metrics.

#### Objectives
- Analyze historical financial performance of JP Morgan Chase  
- Understand revenue composition, cost structure, and profitability trends  
- Evaluate balance sheet strength and capital efficiency  
- Apply financial statement analysis concepts in a real-world context  

#### Key Areas Covered
- Income statement analysis  
- Balance sheet and cash flow interpretation  
- Profitability and efficiency ratios  
- Trend analysis of key financial metrics  
- Business and segment-level understanding  

---

### 2. Stock CAPM Analysis

A Capital Asset Pricing Model (CAPM) based analysis to estimate the expected return of a stock by evaluating its systematic risk (beta) and relationship with market returns.

#### Objectives
- Calculate beta using historical price data  
- Apply CAPM to estimate expected return  
- Understand risk–return tradeoff in equity investing  
- Strengthen grasp of core capital markets theory  

#### Key Areas Covered
- Stock and market return computation  
- Beta estimation using regression analysis  
- Expected return calculation using CAPM formula  
- Risk-free rate and market risk premium assumptions
